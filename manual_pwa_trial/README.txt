院内マニュアル PWA v0.4

公開場所: GitHub の manual-app リポジトリ内 manual_pwa_trial フォルダ
既存の同名ファイルを差し替え、latest.json を同じフォルダに追加してください。

【管理者】
1. アプリでマニュアルを編集
2. 「公開用データを書き出す」で latest.json を保存
3. GitHub の manual_pwa_trial/latest.json を新しいファイルで置換して Commit changes

【職員】
アプリで「最新版に更新」を押し、確認後に置換。
ネット接続が必要。取得後は端末内に保存されオフライン閲覧可能。

重要:
・GitHub Pages上の latest.json は一般公開されます。院内機密・個人情報は載せないでください。
・更新は全件置換です。更新前に端末データをバックアップしてください。
・現在は認証・編集権限の制御なし。全端末で編集可能です。
・PWAの古いキャッシュが残る場合、オンラインで再起動してください。
